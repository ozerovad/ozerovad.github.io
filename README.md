# ВАД — озеро в движении

Интерактивный сайт на Three.js, использующий ранее созданную модель Вадского озера с контуром, обведённым по изображению.

## Локальный запуск

```sh
cd sites/lake-journey
npm run dev
```

Откройте http://127.0.0.1:4173. Установка зависимостей и сборка не нужны: библиотека сохранена в `dist/vendor/`.

## Какие файлы редактировать

| Файл                    | Содержимое                                                          |
| ----------------------- | ------------------------------------------------------------------- |
| `dist/js/content.js`    | Все факты, главы, координаты меток, названия и ссылки на источники. |
| `dist/js/lake-scene.js` | Трёхмерная сцена, загрузка модели, свет, камера, тени и масштаб.    |
| `dist/js/main.js`       | Прокрутка, главы, карточки, сохранённые заметки и поиск.            |
| `dist/styles.css`       | Чёрная рамка, цвета, типографика и мобильная вёрстка.               |
| `dist/index.html`       | Структура страницы и доступные элементы управления.                 |
| `dist/assets/lake.glb`  | Экспорт файла `output/lake_model/lake_scene_traced.blend`.          |

## Как работает путешествие

1. Высота страницы — 650 высот экрана. Используется обычная прокрутка браузера без перехвата колеса мыши.
2. Положение прокрутки преобразуется в число от 0 до 1. Движение камеры слегка сглаживается. При системной настройке уменьшения движения сглаживание отключается.
3. Камера перемещается между шестью точками из `content.js`.
4. Ортографическая камера смотрит на модель сверху. Направление «вверх» совпадает с осью +X: озеро расположено вертикально, как на вашем эскизе.
5. Метки — обычные кнопки, доступные с клавиатуры. Координаты исходного изображения преобразуются в трёхмерные точки, затем — в координаты экрана.
6. Метки появляются рядом с соответствующей главой. Точки вне кадра и под текстовой карточкой скрываются.
7. Заметки сохраняются только в хранилище текущего браузера. Серверного сбора данных нет.

## Координаты

Исходное изображение имеет размер 1060 × 634 пикселя. На одну единицу модели приходится 10 пикселей. После экспорта:

```js
x = (pixelX - 530) / 10;
z = (pixelY - 317) / 10;
y = heightAboveGround;
```

Чтобы добавить заметку, скопируйте объект из массива `discoveries`, задайте уникальный `id`, координаты `pixel` и подтверждающие источники `sources`. Метки тематические: они не обозначают измеренные географические координаты. Положение источника-воклины условно.

## Данные и ограничения источников

Предоставленная статья Руниверсалиса вернула ошибку доступа 403. Ссылка сохранена в справочнике, но статья не использована как подтверждение. Доступные источники перечислены в `SOURCES.md`.

Площадь водного зеркала 56 га отделена от площади памятника природы 145,4 га. Противоречивые размеры и глубины приведены рядом с названиями источников. Исторические измерения пещеры имеют даты и не описывают её нынешнюю доступность.

Контур озера взят из обведённой модели. Деревья, здания, глубины и небольшие перепады рельефа условны.

## Повторный экспорт

Скрипт `export_model.py` открывает исходную модель, применяет модификаторы в памяти, объединяет объекты с одинаковыми материалами и записывает `dist/assets/lake.glb`. Исходный файл модели не перезаписывается.

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python export_model.py
```

## Проверки

```sh
npm run check
```

В браузере проверены загрузка модели, переходы между главами, карточки с источниками, сохранение заметок, поиск и общий вид карты. Включена библиотека Three.js версии 0.180.0; лицензия находится в `dist/vendor/LICENSE`.
